# Gapino

Persian-first (RTL) AI chat application. A small Flask backend serves the static
frontend and proxies chat requests to the GapGPT API, persisting conversations in
a PostgreSQL database (Supabase). The frontend is plain HTML/CSS/JS — no build
step for application code, only a vendor-asset copy for third-party libraries.

## Features

- Streaming chat responses over Server-Sent Events.
- Markdown rendering with syntax highlighting (highlight.js) and task lists.
- LaTeX / math rendering with MathJax, vendored locally so it works offline.
- Image input and image generation through the GapGPT API.
- Multiple chat models, pinned conversations and per-user profile/theme state.
- Installable PWA with a light/dark theme.


## Requirements

- Python 3.11+
- Node.js 18+ (only to build the frontend vendor assets)
- A PostgreSQL database (Supabase-compatible)
- A GapGPT API key

## Setup

1. Create the environment file and fill in your values:

   ```bash
   cp .example.env .env
   ```

2. Install the backend dependencies:

   ```bash
   python -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```

3. Install and build the frontend vendor assets:

   ```bash
   npm install
   npm run build
   ```

4. Run the server:

   ```bash
   python backend/server.py
   ```

   The app is then available at `http://localhost:3000`.

## Environment variables

| Variable                   | Required | Description                                                         |
| -------------------------- | -------- | ------------------------------------------------------------------- |
| `PORT`                     | no       | HTTP port (default `3000`).                                         |
| `HOST`                     | no       | Bind address (default `0.0.0.0`).                                   |
| `FLASK_DEBUG`              | no       | Set to `1` for Flask debug mode.                                    |
| `DATABASE_URL`             | yes      | PostgreSQL connection string.                                       |
| `USE_LOCAL_POOL`           | no       | `1` keeps an in-process connection pool (default `1`).              |
| `GAPGPT_API_KEY`           | yes      | API key for the GapGPT service.                                     |
| `GAPGPT_API_URL`           | yes      | Chat completions endpoint.                                          |
| `IMAGE_GENERATION_API_URL` | no       | Image generation endpoint (derived from `GAPGPT_API_URL` if unset). |
| `SESSION_SECRET`           | no       | Signs session cookies (falls back to `GAPGPT_API_KEY`).             |

## Development

Format and lint:

```bash
npm run format          # Prettier for HTML/CSS/JS/JSON/Markdown
black backend           # Python formatting (see pyproject.toml)
ruff check backend      # Python linting
```

The Python tooling is listed in `requirements-dev.txt`:

```bash
pip install -r requirements-dev.txt
```

## Deployment

`vercel.json` builds the frontend static assets (`npm run build`) and deploys
`backend/server.py` as a Python function. Configure the same environment
variables in the Vercel project settings.
